# Gebya Minch Marketplace

ገበያ ሚንጭ ገበያ

A local marketplace platform for buying and selling products and services in Ethiopia.

## Features

- User registration and login
- Product listing
- Product search
- Category filtering
- City filtering
- Product images
- Favorites
- Seller dashboard
- Buyer dashboard
- Business directory
- Product reviews
- Product reporting
- Payment records
- Admin dashboard
- Product moderation
- Business verification
- Announcements

## Technology

- Node.js
- Express.js
- SQLite
- JWT Authentication
- bcryptjs
- Multer
- HTML
- CSS
- JavaScript
